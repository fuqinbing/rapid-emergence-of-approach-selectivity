This Github project supports the research paper titled "Rapid emergence of approach selectivity in a biologically structured neural model with spike timing-dependent plasticity".
It includes the source code and the data sets used in this research.
The data sets include synthetic motion, real-physical ball motion, dashcam recording motion, drone cam recording motion. All are represented in GIF-format. Owing to restrictions of size, they are divided and compressed.
The source code was written in C#, named "SNN_Collision_github.cs" which articulates the main algorithms.
